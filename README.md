# Weyland LaBelle — Personal Website

This repository contains the source code for my personal website, hosted using GitHub Pages and connected to my custom domain **weylandlabelle.com**.

The site includes:
- **Home page** (index.html)
- **Resume**
- **Portfolio**
- **Newsletter**
- **Contact page**

## Features
- Fully custom HTML/CSS pages
- Mobile‑friendly layout (in progress)
- Custom domain connected through GoDaddy
- Secure HTTPS (GitHub Pages + Let’s Encrypt)

## Deployment
This site is deployed automatically through GitHub Pages.  
Any changes pushed to the repository update the live site instantly.
